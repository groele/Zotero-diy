# MetaRef for Zotero 11.0.1

修复论文标题富文本工具栏的显示位置和编辑对象识别。在 Zotero 的“信息 → 标题”字段中开始编辑时，显示下标、上标、粗体、斜体、保持大小写和小型大写六个按钮；按钮作用于当前标题的选中文字，预览位于按钮下方。旧版 `linter-for-zotero.xpi` 仅作为交互参考，11.0.1 继续使用独立的 MetaRef 插件身份。

本次通过 210 项单元测试、ESLint、AutoCorrect、插件和测试代码的 TypeScript 检查以及生产构建。真实 Zotero 端到端测试未能在本次运行中完成：本机已有 Zotero 进程，测试框架未能启动隔离的第二个实例。此前 11.0.0 版本的中英文各 43 项实机测试不能代替此修复的实机验收。
