# MetaRef for Zotero 12.2.0

- 设置面板新增七个分区的快捷跳转、匹配数量提示、规则一键展开／收起。
- 搜索细化到设置项，支持名称、说明、设置键及空格分隔的多个关键词；匹配子选项时保留父开关，清空后恢复原来的展开状态。
- 缓存本地化搜索文本及控件关系，减少每次输入时的 DOM 遍历；API 密钥和输入值不进入搜索索引。
- 并发数量只保存 1–16 的整数，错误反馈明确，离开输入框恢复上次保存值。
- 缩写和标题术语文件先校验再启用；取消、格式错误、空文件不覆盖原路径，同一路径重新选择时读取最新内容。
- 校验标题术语字段及正则格式，减少执行中才暴露的数据错误。
- 修复快速重开菜单后同一命令可能重复执行的问题，并补充连续三轮查询、打开与关闭的检验。
- 完善输入框、单选组、状态反馈和键盘焦点的无障碍关联，优化窄窗口布局及空路径、忙碌状态下的按钮可用性。

面向 Zotero 10.0.x，目标 Firefox 140。现有 MetaRef 身份与偏好空间保持不变，可从 12.1.0 直接更新。更新清单与安装包仍位于 `groele/Zotero-diy/MetaRef-for-Zotero/dist`。

验收范围见 [设置面板审查](../settings-panel-audit-2026-10-09.md) 与 [安装包验证](../../dist/verification.json)。
