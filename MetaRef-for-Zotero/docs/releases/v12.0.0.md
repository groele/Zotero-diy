# MetaRef for Zotero 12.0.0

- 将 JavaScript 构建目标更新到 Firefox 140，并将插件清单支持范围对齐到 Zotero 10.0.x。
- 修复期刊文章预印本识别：复用元数据更新工具的 DOI/URL 识别逻辑，并在结果报告中提供“尝试更新元数据”操作。
- 自动更新地址和安装包下载地址统一指向 `groele/Zotero-diy` 仓库内的 `MetaRef-for-Zotero/dist`。
- 主标题格式工具栏仅在标题编辑器聚焦时显示，离开标题区域后自动隐藏。

插件 ID、资源命名空间及设置前缀保持不变。11.0.7 及更新版本沿用本仓库自动更新地址；11.0.6 及更早版本需先手动安装 11.0.7。目标 Zotero 10.0.x；本版本实机兼容性已在 Windows Zotero 10.0.6 验证。
