# MetaRef for Zotero 11.0.2

修正标题格式工具栏的目标位置。11.0.1 错误地把按钮和预览放在下方“信息 → 标题”字段；11.0.2 改为识别 Zotero 顶部黑色加粗的主标题编辑框，并在该模块内显示下标、上标、加粗、斜体、保持大小写和小型大写按钮。下方标题字段不再显示这组控件。标题快捷键也只对正在编辑的顶部主标题生效。

定位依据是本机 Zotero 10.0.5 的 `itemPaneHeader.js` 和运行窗口的可访问性结构：顶部主标题是 `item-pane-header .title editable-text`，没有 `fieldname="title"` 属性；旧版六个按钮实际出现在下方 `itembox-field-value-title`。构建、210 项单元测试、ESLint、AutoCorrect，以及插件和测试代码的 TypeScript 检查通过。桌面当前处于锁定状态，11.0.2 尚未完成可视验收；此前隔离端到端测试也未能在已有 Zotero 进程旁启动。
