# MetaRef for Zotero 12.1.0

- 新增条目自动整理改为后台合并队列：短时间的新增通知去重并合并，减少重复执行，不再阻塞 Zotero 的导入通知。
- 执行前重新检查自动开关和条目状态；卸载时取消等待中的任务，处理中收到的条目在下一批串行执行。
- 内置期刊数据与索引跨批次复用；自定义文件在批次结束后释放缓存，保留「重新读取」能力。
- 批处理进度按阶段节流，减少界面绘制，保留完整保存、失败和取消结果。
- 优化设置页开关联动；明确新增条目自动整理、MetaRef 检查修复、更新元数据后检查的适用范围、保存行为和覆盖模式。
- 修复标题工具栏延迟打开竞态，点击其他区域后不会被旧回调重新打开；保留键盘操作、选区及嵌套格式。
- 结果和设置窗口改用原生窗口关闭通知释放等待及观察者，避免文档导航或提前关闭造成跟踪状态残留。

面向 Zotero 10.0.x，JavaScript 目标为 Firefox 140。插件身份及设置空间保持不变，12.0.0 可直接更新。自动更新清单和安装包统一位于本仓库 `MetaRef-for-Zotero/dist`。

本次验收与性能数据见 [当前审查](../current-review.md)、[性能检验](../performance-audit-2026-10-09.md) 和 [安装包验证记录](../../dist/verification.json)。外部服务采用受控响应验证；数据库快照未在线刷新。
