# MetaRef for Zotero 11.0.3

修复期刊数据库设置页的“清除路径”操作：先确认内置名单可读取，再清除自定义路径，等待侧栏与条目列刷新完成，并显示恢复后的内置记录数。若内置名单校验失败，保留原自定义路径并显示错误。标题预览框改用 MetaRef 专属的 DOM ID，避免清理时触及其他插件的同名元素。

在 Windows Zotero 10.0.5 中，43 项真实端到端测试全部通过，包括顶部黑色加粗主标题中的六个格式按钮、数据库重置和生产 XPI 安装。另通过 210 项单元测试、生产构建、插件及测试 TypeScript、ESLint 和 AutoCorrect 检查。外部元数据服务的实时可用性与 macOS/Linux 尚未验证。
