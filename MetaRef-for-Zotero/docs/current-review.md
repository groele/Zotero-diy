# 当前实现与验收范围

版本：12.1.0。目标：Zotero 10.0.x；本次真实运行环境为 Windows Zotero 10.0.6。顶部主标题格式工具栏支持键盘操作和选区保留，并能准确切换嵌套格式。

## 菜单和窗口

MetaRef 内 22 项功能直接显示；设置页分类只控制入口显示。真实测试打开原生右键菜单并触发 command 事件，连续两次执行化学式整理及保存，并分别查询 ESI 与 Nature Index。查询窗口提供明确结果、匹配依据、实际来源及数据错误。

窗口关闭使用 Gecko 原生 `domwindowclosed` 通知判断，避免文档导航／unload 与窗口生命周期混淆；关闭窗口后释放跟踪状态及原生观察者，不影响后续设置工具。测试先清理其他测试产生的报告，保证只验证本次点击产生的新窗口。

## 期刊索引

标题不使用图标，移除 Zotero 为自定义标题保留的空图标位及附加刷新按钮，保留原生展开／折叠控件；独立侧边入口使用新的轻量图标。更新数据库通过设置页的「重新读取」完成，菜单查询也会重新读取数据。

ESI 展示学科名称，Nature Index 使用“名单内期刊”等明确状态；左侧标签轻量显示，右侧结果用较大的半粗文字强调。同一依据只显示一次，不同依据分别附在结果下方，仅在实际命中时显示。底部以较轻文字呈现数据库版本及一句简短说明，完整解释可通过提示查看。数据库读取失败与未匹配明确区分，回退来源按实际使用的数据标注。

侧栏和菜单共用展示逻辑，中文显示中文学科、英文显示英文学科；未匹配与数据库不可用使用不同文案和状态。列表列格式可自定义。识别不修改文献字段、Extra 或标签。

## 清理

移除旧版本设置迁移、版本比较模块、已弃用的 onUpdateInBatch API、旧快捷键加号别名、旧式对象键期刊列表输入、废弃菜单上下文回退、旧安装包别名、旧版本压缩包、过时审查和重复验证文件、未使用的图标尺寸。

使用独立 MetaRef 身份及设置空间，不读取或迁移原设置。ESI 查询改为 `tool-query-esi` 手动工具，Nature Index 查询为 `tool-query-nature-index`；没有写入字段／标签的历史规则身份。ESI 数据路径和列显示格式归入 insights 设置。

保留有实际用途的 JSON 数组／标准包装对象、CSV 表头别名和编码容错；保留上游版权及许可证。不删除资料库条目的人工字段或标签。

## 本次逻辑与性能优化

新增条目的通知不再等待自动整理完成；队列在至少 500 毫秒的窗口合并、去重，并串行派发批次，处理中收到的新增事件归入下一批。执行前重新检查自动开关、条目存在性、可编辑性、群组设置、订阅与回收站状态；卸载时取消尚未执行的任务。手动工具仍只由用户触发。

内置数据和派生索引跨批次复用，自定义文件缓存在批次结束时释放；数据库「重新读取」仍清除完整缓存，失败读取不缓存拒绝结果。缓存数量随固定内置资源限制，不随处理条目数增长。

进度绘制在同一阶段最多每 100 毫秒刷新一次，开始、阶段切换和完成强制刷新；完整保存与失败计数不受绘制节流影响。设置页预先计算开关联动关系，避免每次操作重复扫描全部控制项。

修复标题点击的延迟回调竞态：点击其他区域或卸载后取消待打开回调，打开前检查当前焦点与编辑器连接状态。原生窗口回归检验覆盖迅速移开焦点后工具栏不会重新显示，以及鼠标和键盘格式化选区保留。

## 验证

221 项单元测试（34 个文件）。真实 Zotero E2E 的最终结果、生产包 SHA256 和安装清单由 `dist/verification.json` 记录。真实 E2E 覆盖自定义数据库、设置窗口、自动处理开关、菜单命令、侧栏对齐、事务恢复、撤销、通知、快捷键、PDF、160 条真实条目的保存与性能计数，以及生产 XPI 安装。[性能检验](performance-audit-2026-10-09.md) 记录同机优化前后的场景与测量范围。

原 `Linter-for-Zotero` 目录删除后，11.0.6 及更早版本的旧更新地址不可达，需要手动安装当前版本一次；从 11.0.7 开始使用新目录更新地址。更新清单和 XPI 均指向 `groele/Zotero-diy` 中的 `MetaRef-for-Zotero/dist`。

外部元数据服务采用受控响应验证；尚未证明实时服务连通性或全部第三方插件组合。未实机验收 macOS／Linux。Windows 原生文件选择器的路径边界通过替换返回值验证，没有自动点击系统文件对话框。
