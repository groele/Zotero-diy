# 11.0.0 深入检验与优化记录

日期：2026-10-09。生产安装包在 Windows / Zotero 10.0.6、Gecko 140 的独立配置和独立 SQLite 文库中验证。主用户文库未作为写入目标。

## 本轮发现与修复

| 问题 | 影响 | 处理与验证 |
| --- | --- | --- |
| 刷新先清空现有结果 | 网络故障、取消后失去可用列表 | 同类型结果保留到成功替换；失败、取消与空返回专项实机检查 |
| 排序再次进入获取流程 | 增加等待与服务请求，损失选择与焦点 | 直接本地排序；实机断言获取调用数为 0，并保留来源编号 |
| 获取完成后任务被删除 | 延迟进入视区的卡片被旧任务校验拒绝匹配 | 匹配绑定当前列表、条目及渲染代次；真实 SQLite 匹配，交叉区回调队列受控触发 |
| 取消只阻止界面提交 | 排队与元数据补全可能继续消耗时间和请求容量 | 订阅取消传递到原生 XHR；最后订阅终止传输；排队取消释放容量 |
| 多面板共用传输时直接取消 | 可能中断其他面板的有效请求 | 分订阅计数，仅取消自己的等待；两订阅实机只发 1 次 HTTP |
| 刷新更换卡片对象 | 选择、焦点和过滤计数丢失 | DOI / arXiv / 文献文本稳定身份恢复交互状态，不作为写入文库的身份依据 |
| 在线缓存缺少部分状态 | 再次读取可能显示为完整列表 | 保存来源、部分标记和预计数量；新获取签名使旧在线快照重新获取 |
| 安装包与更新清单生成时机不同 | 构建失败可能先公布版本，散列不匹配 | 编译成功且完成打包后生成 SHA-256 清单，并同步根目录生产安装包 |

保留原 XPI 的紧凑布局、原生面板图标、引文与元数据、搜索、编号、多选及右键菜单。减少浮动获取提示，进度集中在面板；设置页增加版本说明入口。

实机使用真实 DOM、Reader、SQLite、缓存文件和 XHR。限流、超时、503、队列等连接本机故障服务器；延迟 API、候选完整性、出版社格式样例和交叉区调度使用明确标注的受控夹具。此类结果证明处理逻辑，不能代表所有出版社当前线上页面均通过。

## 本次性能观测

| 场景 | 观测 |
| --- | --- |
| 1,000 张原生卡片 | 渲染约 66 ms，期间事件循环运行 10 次 |
| PDF 缓存命中 | 约 3 ms；Reader 新打开次数与重新扫描次数均为 0 |
| 排序 | 14 条卡片约 9 ms；获取调用数 0 |
| 最后订阅取消原生慢请求 | 约 31 ms 内结束等待，活动请求和缓存为空 |
| 可选补全期限 | 配置 40 ms；含额外 20 ms 观察共约 73 ms，未留下活动请求 |
| 真实 arXiv 论文 | 提取 40 条，读取 15 页中的 6 页，约 2.14 s |

均为单次实机测量，网络、文库和设备会影响结果；没有进行跨设备统计或旧版同条件对照，不声称统一百分比加速。

联网样本 `10.1038/nphys1170`：参考文献 10 条、施引文献 12 条、相关文献 7/10。部分相关列表保留明确标记，服务覆盖与限流仍会影响数量。

## 仍需持续改进的范围

1. `uncaught exception: undefined` 匿名记录仍存在，没有可定位来源和堆栈。已有历史控制实验未定位到具体业务模块；功能及启停断言通过，仍不能宣称日志无异常。原始记录保留。
2. 扫描件无文本层无法直接解析；OCR、旋转混排和更多出版社真实样本需要另行实现和评估。
3. 本轮不保证免费 API 永远可用。OpenAlex 相关样本仍为部分列表；服务额度、数据覆盖及登录墙无法由插件补造。
4. CNKI / Jasminum 账户流程与第三方委托任务未完整实测；它们的取消目前保证不提交过期界面结果，不承诺所有委托任务物理终止。
5. Connected Papers 远程建图、全部第三方插件组合、其他操作系统与长期内存剖析未完整验证。
6. 仅支持 Zotero 10.0.0–10.*。参见 [Zotero 10 开发接口](https://www.zotero.org/support/dev/zotero_10_for_developers)；未来主版本需重新核验，插件 11.0.0 不代表 Zotero 11 支持。
