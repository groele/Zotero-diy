## 发现与修复

| 问题 | 影响及证据 | 修复 |
|---|---|---|
| P1 双栏 PDF 顺序错误 | 原实现输出 1、4、2、5、3、6 | 按坐标重建行与列，恢复 1–6 阅读顺序 |
| P1 作者年份书目无法提取 | 实机夹具提取为 0 条 | 支持姓名缩写、年份括号、跨行条目 |
| P1 编号步骤被当成书目 | 无参考文献标题的操作步骤被提取为 3 条 | 加入书目证据、连续编号和标题区段判断 |
| P1 DOI 吞入后续文字 | DOI 后的期刊文字被拼进标识符 | 保留文本边界并规范化 DOI |
| P1 异步结果写入其他条目 | 延迟响应在切换条目或来源后仍提交 | 每个面板使用任务代次和完整身份校验 |
| P1 本地匹配忽略 DOI 冲突 | 同名但不同 DOI 的条目被接受 | 标识符冲突优先拒绝，限定文库 |
| P1 嵌套 HTTP 重试 | 原生 HTTP 的长时间重试叠加插件策略 | 禁用嵌套重试，明确超时、预算、有限退避 |
| P1 导入超时后重复写库 | 翻译器晚到结果与并发导入可能重复保存 | 翻译器仅返回元数据，插件统一串行写库 |
| P1 撤回破坏已有关系 | 原数据与新批次关系未区分 | 记录每条新增关系方向、集合成员与附件归属 |
| P1 撤回批次 ID 冲突 | 同秒重复操作可共享旧批次标识 | 增加毫秒与序号，校验精确批次、文库和父条目 |
| P2 工具库冷启动接口失效 | 旧库依赖已移除的 Gecko / Reader 接口 | 工具库升级，仅构造所需组件 |
| P2 原生侧栏标题与图标 | 标题定位与本地化属性错误 | 区分标题 `.label` 与侧栏 `.tooltiptext`，验证五个图标资源 |
| P2 功能布局偏离原包 | 大按钮行替代原生标题操作与卡片 | 恢复标题图标、搜索、元数据卡片、多选和菜单 |
| P2 关系图入口失效 | 旧高级搜索按钮 ID 在 Zotero 10 不存在 | 在当前工具栏创建独立入口 |
| P2 首次后台读取 PDF 的加载竞态 | 应用初始化先于 PDF 文档加载完成 | 分阶段等待应用、文档及文本层，均有截止时间 |
| P2 条目树冷启动竞态 | 界面就绪时条目树仍可能为空 | 等待窗口的真实条目树与集合树关联完成 |
| P1 同一条目重复渲染清空获取结果 | 最后一轮实机出现无 HTTP 错误却显示 0 条的竞态 | 保留同一身份的卡片与任务，避免重置来源 / 类型，新增专项回归 |
| P2 来源 / 类型缓存混用 | References、Citations、Related 未充分隔离 | 分类型签名和缓存键，部分列表保留来源与总数 |
| P2 刷新失败丢失可用数据 | 在线服务失败后列表被清空 | 保留有效快照，显示离线缓存状态和部分列表标记 |
| P2 多窗口资源混用 | 关闭一个窗口可能卸载共享插件状态 | 共享数据服务，各窗口独立拥有图形资源与样式 |
| P2 未使用模块与依赖 | 旧注入、轮询、重复 D3 和大量 NLP 依赖 | 删除无引用模块与脚本，运行依赖收敛为三个直接依赖 |
| P2 长期缓存与请求排队增长 | 缓存条目数与等待请求缺乏完整上限 | 缓存 250 / 500 项；默认最多 64 个排队请求且等待会到期 |
| P2 悬浮详情和键盘体验 | 获取详情可能附带多源请求，过滤后导航可到隐藏行 | 元数据悬浮不联网，方向键只遍历可见卡片，浮窗可滚动 |

## 实机测试方法

- 安装真实生产 XPI 到 `refnexus-z10-release-*` 独立配置。
- 独立测试驱动通过 Zotero 原生启动流程加载测试脚本，不向生产插件开放执行接口。
- 五个确定性 PDF 用于单栏、双栏、作者年份、编号正文和 120 页文档测试。
- 公开真实论文 PDF：`https://arxiv.org/pdf/1706.03762`。
- 实际 HTTP 使用 Zotero XHR；限流、503、超时和并发测试连接本机故障服务器。
- 导入与撤回写入独立 SQLite 文库；仅翻译器超时、在线延迟等故障用受控替身注入。
- 实际联网验证 Crossref、OpenAlex 和 arXiv；响应未替换为测试数据。

最终数量、耗时与安装包散列见下方自动生成结果及 `docs/evidence/`。

## 仍有边界与未解决项

1. **启动匿名异常待定位。** 多次配置记录到 `uncaught exception: undefined`，没有来源或堆栈。去掉关系图、界面初始化和工具组件的控制实验仍能看到该条记录；未证明是某个业务模块导致，也未证明无影响。功能与生命周期断言通过，但不能据此宣称日志完全无异常。报告保留原始记录。
2. 纯扫描件没有文本层时无法提取；未提供 OCR。复杂旋转布局、非常规参考文献排版和跨栏混排仍需更多真实样本。
3. 在线服务覆盖、限流和数据更新会影响数量。实测相关文献仅获得 7/10，界面明确标注；缓存恢复不能补造缺失条目。新网络失败会显示失败或缓存，而非保证服务永远可用。
4. Connected Papers 的图形入口与本地应用加载已验证；依赖有效服务密钥的远程建图尚未进行完整验证。CNKI 账户流程、其他翻译插件组合、原插件的付费 / AI 功能未声明全等价。
5. 卡片与图标使用真实 DOM / 资源加载验证，未完成跨平台截图审阅、长时间内存剖析或与主配置全部第三方插件的组合测试。
6. 主配置当时加载的是 10.1.0。本次验证包为 10.2.0；主配置的使用效果需要安装新包后检查，不能用独立测试结果替代升级状态。
