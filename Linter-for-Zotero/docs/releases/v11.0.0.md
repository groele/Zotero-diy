# MetaRef for Zotero 11.0.0

## 概览

这是一次大版本更新：插件完成从旧 Linter 身份到 MetaRef 独立产品身份的切换，并重组了期刊索引、菜单、设置和结果展示。

## 破坏性变更

- 插件 ID 改为 `metaref@groele`，资源命名空间改为 `metaref`，运行时实例改为 `Zotero.MetaRef`。
- 设置前缀改为 `extensions.zotero.metaref`。旧设置不会迁移，旧插件实例和旧配置应在安装前移除。
- ESI 与 Nature Index 查询改为独立手动工具 `tool-query-esi` 和 `tool-query-nature-index`；旧规则 ID、旧批处理别名和旧快捷键加号别名已删除。
- 旧式以刊名作为 JSON 对象键的期刊名单格式不再接受，请使用 JSON 数组或标准 `journals`／`venues` 包装对象。
- 发布包唯一名称为 `metaref-for-zotero.xpi`，不再提供旧安装包别名。

## 新功能与界面

- MetaRef 菜单的 22 项操作直接展开，不再使用二级菜单。
- 期刊索引侧栏采用紧凑的左右对齐文本布局：结果突出显示，匹配依据去重，数据库版本集中显示。
- 侧栏标题不显示附加图标或刷新按钮；数据库重新读取统一在设置页完成。
- ESI 与 Nature Index 支持独立自定义 JSON／CSV 数据库、逐条校验、错误回退和内置名单导出。
- 新增独立 ESI／Nature Index 列与结果报告，查询不写入文献字段、Extra 或标签。

## 升级步骤

1. 在 Zotero 插件管理器中卸载旧 Linter 或旧 MetaRef。
2. 安装 `metaref-for-zotero.xpi`。
3. 重新配置自动规则、快捷键和 ESI／Nature Index 数据库路径。
4. 先在测试资料库执行少量条目检查，再进行批量整理。

## 验证

210 项单元测试、中文和英文各 43 项真实 Zotero 测试通过；ESLint、AutoCorrect、插件 TypeScript、测试 TypeScript 和生产构建均通过。Windows Zotero 10.0.5 实际安装并验证生产 XPI。

## 回滚

卸载 11.0.0 后重新安装此前保留的插件包。由于 11.0.0 使用独立插件身份，旧插件设置仍由 Zotero 单独保存，不会被本版本改写。
