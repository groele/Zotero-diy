# ZoteroPreview 40.1.7 稳健性复查

日期：2026-10-14。复查范围：源码、原生栏目排序、设置页事件、异步生命周期、引用缓存、复制、版本与自动更新通道。

## 已发现并修复的问题

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 异步排序期间可再发起同一侧栏排序 | 重复移动、任务交错 | 每个侧栏独立串行执行；进行中的变更合并为一次后续检查 |
| 原生排序默认触发全栏目渲染 | 排序与渲染可能互相触发 | 使用 `render:false`，对缺少预览内容的栏目独立安排刷新 |
| 禁用后等待中的原生排序仍可继续回退移动 | 生命周期结束后继续操作 UI | 捕获生命周期令牌，在等待返回后检查；停止创建新位置任务 |
| 观察器 disconnect 抛错可提前中断清理 | 事件、状态和资源残留 | 隔离每个清理步骤异常；重复监听同一 owner 时直接返回 |
| 阅读页父文献被移入回收站后仍可持有预览 | 复制已删除文献的旧内容 | 通知时立即清空 payload 并禁用栏目；渲染前重新核对文献状态 |
| 相同缓存键替换时重复增加字节计数 | 提前驱逐、错误的容量统计 | 写入前扣除该键原有占用 |
| DOM 替换后复制反馈计时器仍引用旧节点 | 短时保留已移除节点 | 替换 DOM 前取消并清空反馈计时器与映射 |
| 设置片段卸载和窗口卸载不是同一个事件 | 设置页监听器可能晚于片段释放 | 捕获根片段的非冒泡 unload；与禁用、窗口关闭共用清理 |
| 本机更新地址正确但远端仍只有 40.1.4 | 40.1.6 用户无法获取本次修复 | 将新版源码、XPI 和哈希清单同步到既有维护通道 |

## 验证结果

`pwsh -NoProfile -File ./test.ps1` 通过：原生侧栏 18 项、Gecko 153 4 项、发布一致性 2 项，共 24 项。

另完成 JavaScript 语法检查、14 个 XPI 文件逐项 SHA-256、清单版本/兼容范围/更新链接/安装包哈希和 Fluent 本地化检查。侧栏与设置页测试在冻结内建对象的模拟沙箱运行。

新增测试覆盖异步任务串行与突发变更合并、禁用中断、删除通知、缓存替换计数及观察器异常。此前复制动画、阅读文献归属、缓存复用、快速切换、位置迁移和隐藏按钮回归继续通过。

- Zotero 11 / Firefox 153 的实机验收仍未完成；冻结内建对象测试和源码审计不替代真实 Gecko 运行。
- Zotero 8/9、其他操作系统、暗色模式及各类阅读格式尚未全面验收。
- 若其他插件持续强制采用不同的栏目顺序，当前合并机制可避免本插件自身的并发任务，但多个插件之间的排序冲突仍需联合实测。

本次结果支持“已修复并通过自动回归”，不支持“所有运行环境都已保证无问题”。
