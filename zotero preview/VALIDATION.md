- Zotero 10.0.6 的独立 PDF / 网页阅读窗口没有原生 item-details 侧栏，本次通过打开窗口和检查 reader.xhtml 确认。此版本支持主窗口内的阅读标签页。
- Zotero 8/9、其他操作系统、暗色模式、EPUB、没有父文献的附件等没有全部完成桌面验收。
- 多选预览逻辑通过单元测试；多选时原生条目侧栏的实际可见性没有完成桌面验收。
- 测试使用临时加载源码；XPI 安装后、应用重启后的持久加载尚未验证。
- 原工作目录不是 Git 仓库；发布通过独立克隆同步到维护仓库。
