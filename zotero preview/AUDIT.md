# V40 项目审查与改进记录

审查对象：从 `zoteropreview V40.xpi` 恢复的 V40.0.0 运行文件；审查范围包括启动与关闭生命周期、选择变化与多条目预览、复制交互、偏好设置、Zotero 兼容元数据、本地化、构建和版本更新元数据。

## 已修复并纳入 40.0.1

| 优先级 | 问题 | 处理 |
|---|---|---|
| 高 | 项目外的旧测试固定读取 `zoteropreview-20.0.1-src`，因此它实际没有验证 V40 发布源码。 | 将测试随项目维护，直接针对当前目录运行；增加对版本/更新清单一致性、API 回归、生命周期、翻译和复制控件的检查。 |
| 高 | 多选超过最大预览数时会静默丢弃后续条目，用户无法判断预览不完整。 | 限制计算规模的同时显示本地化条目计数提示；上限仍可在 1–500 间配置。 |
| 高 | manifest 的更新地址指向上游 V40.0.0，派生项目的更新可能继续指向上游包。 | 将主页、更新清单和 XPI 下载地址改为本仓库 `zotero preview` 子目录，并同步 40.0.1 版本。 |
| 中 | 启动/关闭日志绕过 debug 偏好，且保留旧 `0.1` 前缀。 | 仅在 debug 偏好开启时输出，并隔离日志偏好读取异常，避免影响插件生命周期。 |
| 中 | 窗口挂载目标短暂缺失时只以 50 ms 间隔重试 25 次，约 1.25 秒后停止；延迟构建的侧栏可能错过挂载。 | 改为递增、封顶的 25 次重试；最大单次等待 1 秒，避免高频轮询和无限重试。 |
| 中 | 西语/法语 locale 的运行时错误提示仍为英语。 | 补齐西语、法语运行时文案，包括预览上限提示。 |
| 中 | 项目没有随包提供明确的源码、构建、安装、兼容范围及版权/来源说明。 | 新增 README、变更记录、审查记录、Apache-2.0 上游许可证副本，以及可复现的 PowerShell 构建和测试入口。 |

## 已确认的现有保护

- 预览工作量有可调上限；默认 100，最大 500。
- 修改通知按当前预览所含条目使缓存失效；关闭窗口时清理选择监听、复制监听、重试监听和计时器。
- Quick Copy/CSL 缺失路径会显示状态消息；复制保留内联 SVG、鼠标和键盘交互。
- manifest 声明 Zotero 8.0 到 Zotero 10.0.x；代码通过特性检测和 Reader 候选挂载点覆盖不同窗口结构。

## 后续仍需验证或可继续提升

| 优先级 | 后续工作 | 当前边界与建议 |
|---|---|---|
| 高 | 实机兼容性验收 | 静态检查无法证明 Zotero 8、9、10 的主窗口、Reader、Fluent 菜单和剪贴板接口都能正常工作。发布前应至少在目标 Zotero 10 构建安装 XPI，逐项验收主窗口/Reader 挂载、切换文献、多选、复制以及禁用卸载清理。 |
| 高 | Zotero 10 后续小版本与未来主版本 | `10.0.*` 是当前有界声明；Zotero 11 等未来主版本需要先验证，再更新 `strict_max_version`。建议维护逐版本手工验收矩阵，而不是无限放宽上限。 |
| 中 | 自动化窗口/DOM 集成测试 | 当前 Node 测试验证关键源码契约，但未运行 Zotero Gecko/XUL DOM，也不能模拟真实 Quick Copy、CSL 引擎、焦点导航和插件重载。可在建立 Zotero 测试环境后增加端到端脚本。 |
| 中 | Preview 输出性能与部分失败处理 | 多条目 CSL 预览仍是同步计算；上限能约束输入但高复杂 CSL 样式仍可能短暂阻塞 UI。后续可对大批量样式做性能测量，再决定是否分批渲染或提供取消机制。 |
| 低 | 位置设置与不同版本原生布局 | 挂载点采用多个 ID/Reader 选择器回退。Zotero UI 重构时这些选择器可能变化，建议每个目标版本验收三个位置并保留挂载失败日志。 |

## 验证记录

- `pwsh -NoProfile -File ./test.ps1`：7 项 Node 回归测试通过，3 个运行 JavaScript 文件语法检查通过，XPI 成功生成并重新打开验证。
- 构建脚本核对打包清单和版本；当前 XPI 包含 14 个运行文件。
- 尚未在 Zotero 桌面端手工安装或执行真实 Reader/剪贴板测试。因此此处结论是静态检查与包结构通过，不能替代实机兼容性验收。
